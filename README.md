# Field_Ops

Field Service Management system: customers submit service requests, dispatchers create
work orders and assign technicians, technicians complete jobs, and customers are invoiced.

Built over 12 weeks to grow as a .NET backend developer and learn Angular.

## Tech stack
- ASP.NET Core (.NET 10), Clean Architecture, CQRS (MediatR), FluentValidation
- EF Core + PostgreSQL
- Angular (standalone components, signals, Angular Material)
- xUnit, Testcontainers, Playwright
- Docker Compose, GitHub Actions
